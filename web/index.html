Technical Architecture

100% Local-First Engine

How SocialBreak protects your attention without compromising your privacy or personal data.

🛡️

Local DNS Sinkhole

Uses Android's VpnService to construct a local loopback TUN interface. Blacklisted domains (adult, casino, gaming, addictive social) are dropped locally at 0.0.0.0 with zero network hops.

⚡

Zero-Allocation Accessibility

Monitors foreground app transitions using lightweight debounced event queues. Keeps CPU usage at 0% when idle and RAM under 30MB PSS.

🔐

Device Admin Anti-Tampering

Leverages native Android DeviceAdminReceiver to prevent impulsive uninstallation during active Hard Mode schedules.

💾

Zero Cloud Telemetry

All daily usage stats, streak logs, and timer configurations live exclusively in local Jetpack DataStore preferences on your phone storage.
